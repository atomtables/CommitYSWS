# Commit YSWS

to run the page just `npm install` `npm run dev` `npm build` `npm run preview` outputs a static page

This is the YSWS page for the Commit YSWS, a YSWS where you work on projects within the YSWS by adding features and fixing bugs, committing your code, and making PRs for every issue you fix. It's a different style of YSWS in general anyway.

Made this because I was kinda interested (in partnership with abominablepug btw).
